Tradier API Connection
Connects directly to Tradier and fetches your full gain/loss history.
Hit Sync Trades in the sidebar anytime to pull the latest.
Stored locally only — never transmitted except directly to api.tradier.com.
Find your token: Tradier → Preferences → API Access → Production API Access (not Sandbox)
Import from CSV
Export a CSV from Tradier and import it here — it merges with existing data and deduplicates automatically.
How to export: Tradier → Account → Export → Gain/Loss (filter by dates) → Export CSV
